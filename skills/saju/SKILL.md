# 평생사주 풀이 스킬 (saju)

생년월일시 하나로 **유료 결제한 것 같은 방대한 평생사주**를 뽑고, 최종 결과는 긴 텍스트 응답이 아니라 **HTML 리포트 파일**로 만든 뒤 `open` 명령으로 열어준다. 풀이가 끝나면 **무엇이든 질문 받는 상담 모드**로 넘어간다.

핵심 원칙: **명식(사주팔자)은 절대 암산하지 않는다.** LLM이 직접 계산하면 절기 경계에서 월주·연주가 틀린다. 반드시 `engine/manse.cjs`로 계산하고, 그 데이터에 **근거해서만** 해석을 쓴다.

---

## 0. 트리거 & 입력 수집

사용자가 "사주 봐줘 / 평생사주 / 내 사주" 등으로 부르면 시작. 먼저 아래 4가지를 받는다:

| 항목 | 필수 | 비고 |
|---|---|---|
| 생년월일 | ✅ | 양력/음력 명시 (모르면 양력 가정) |
| 태어난 시각 | 권장 | 모르면 진행 가능(시주 빠짐 → 정확도↓ 경고) |
| 성별 | 권장 | 대운 방향·배우자 해석에 영향. 모르면 가정+경고 |
| 음력/윤달 여부 | 조건부 | 음력이면 `음력`, 윤달이면 `--leap` |

빠진 게 있으면 **딱 한 번만** 물어보고, 그래도 모르면 가정하고 진행하면서 결과 상단에 경고를 단다. 비개발자 사용자이므로 "양력이에요 음력이에요?" 정도만 자연스럽게 묻는다.

## 1. 명식 계산 (반드시 엔진 호출)

스킬 폴더 기준 경로로 실행한다. `<SKILL>` = 이 SKILL.md가 있는 디렉토리.

```bash
node "<SKILL>/engine/manse.cjs" "1995-08-15 14:30 남" --json
```

- 토큰 순서 무관: 날짜 / 시각 / 성별(남·여) / `음력` / `--leap` 를 공백으로 나열.
- 시각 모르면 시각 토큰 생략 (엔진이 12:00 가정 + 경고 플래그).
- **★ 진태양시(경도) 보정 — 기본 ON.** 한국 표준시는 동경 135° 기준이라 실제 시각보다 빠르다. 엔진이 **기본으로 서울 경도(−32분)** 를 적용해 시지·시간(천간) 경계를 바로잡는다. 경계 시각(정각 등)일수록 시주가 달라진다.
  - 출생지를 알면 도시명 토큰을 붙인다: `부산`(−24분)·`대구`·`인천`·`광주`·`대전`·`제주` 등. 더 정밀하면 `경도127.5` 또는 `--lon=127.5`.
  - 보정을 끄려면 `표준시`(또는 `--no-lon`) — 시계 시각 그대로 계산.
  - 첫 풀이 전에 **출생지(시/도)를 한 번 물어보면** 시주 정확도가 올라간다(모르면 서울 기본). 시 미상이면 보정 영향이 거의 없으니 굳이 안 물어도 됨.
  - JSON `input.offsetMin`·`input.solarBefore/After`·`input.lonLabel`로 보정 내역 확인 가능. 사용자에게 시주를 말할 땐 "출생지(서울 기준) 보정 적용" 정도로 투명하게 언급.
- `--json`으로 받아서 아래 필드를 해석 근거로 쓴다:
  - `palja` (연·월·일·시 간지), `ilgan` (일간 글자/오행/음양)
  - **`counts` (★강약 풀이는 무조건 이걸로)** — 실제 글자 개수 기반:
    - `counts.ohaeng` 오행 개수, `counts.ohaengGrade`(없음/약함/보통/강함/과다), `counts.lacking`(아예 없는 오행)
    - `counts.shipsinGroup` 십신 5그룹 개수(비겁·식상·재성·관성·인성), `counts.shipsinGroupGrade`, `counts.shipsinDetail`(10종 개수), `counts.missingShipsin`(없는 그룹)
    - `counts.sinKangYak` (신강/신약/중화)
  - `kyukguk` (격국), `yongshin` (용신 오행 + 이유)
  - `daewoon` (10년 단위 대운 간지 + 시작나이)
  - `manse.{year,month,day,hour}` (기둥별 십신·12운성·신살)
  - `result.ohaeng`/`result.shipsin` 의 **소수점 값은 내부 가중치다 — 절대 사용자에게 인용 금지** (아래 규칙 참고).

엔진이 실패하면(미설치 등) `engine` 폴더에서 `npm install` 후 재시도. 절대 손으로 명식을 지어내지 않는다.

### ★ 강약 표현 규칙 (가장 흔한 실수 — 반드시 지킬 것)
실제 인기 사주 풀이(포스텔러·점신·명리상담)는 **"재성이 0.9", "오행 3.1"** 같은 소수점을 **절대 쓰지 않는다.** 어색하고 가짜 같다. 강약은 **개수**로만 말한다:
- ✅ "재성이 1개뿐이라 약하고, 관성이 3개로 강합니다", "사주에 **화(火)가 하나도 없어** …", "인성이 없는 무인성 사주라…"
- ❌ "재성이 0.9로 약하고", "오행 목이 3.1이라", "식신 0.6"
- 등급 어휘: 없음 / 약함(1) / 보통(2) / 강함(3) / 과다(4개 이상). `counts.*Grade` 그대로 활용.
- **"없는 오행/없는 십신"은 인기 풀이의 핵심 떡밥**이다(예: "물이 없는 사주", "관성 없는 사주"). `counts.lacking`·`counts.missingShipsin`이 있으면 그 의미를 비중 있게 풀어준다.

## 2. 해석 사전 로드

챕터를 **근거 있고 일관되게** 쓰려면 `references/interpretation.md`를 읽는다. 일간 10종 성격, 십신 의미, 12운성, 주요 신살, 오행↔건강 매핑, 격국·용신 활용법이 들어있다. 모든 해석 문장은 이 사전 + 엔진 데이터에 묶여야 한다. (별점·혈액형식 일반론 금지)

## 3. 평생사주 생성 순서 — 먼저 18장, 그다음 핵심 추정 3종

### 인기 풀이 방식(감명 순서)을 따른다
실제 명리 상담·인기 앱이 쓰는 정통 감명 순서가 있다. 각 장을 쓸 때 이 논리 흐름을 **속으로 거치고** 결론을 풀어낸다(독자에겐 결과를 이야기로):
1. **일간(日干)** 확인 → 나라는 사람의 본질 (제2장)
2. **월령 득실 + 신강/신약** (`counts.sinKangYak`) → 내 기운이 센지 약한지 = 모든 해석의 저울
3. **오행 균형** (`counts.ohaeng`, 없는 오행) → 넘치고 모자란 기운 (제3장)
4. **십신 구조** (`counts.shipsinGroup`, 없는 십신) → 재물·일·관계·공부의 분포 (제4장)
5. **격국·용신** → 사주의 그릇과 평생 약(藥)이 되는 기운 (제5·6장)
6. **신살·형충회합** → 양념 (제15장)
7. **대운·세운** → 시기별 길흉 흐름 (제7·16장, Q&A의 시기 질문)

> 핵심 저울은 **신강/신약**이다. 신강이면 빼주는 기운(식상·재성·관성)이 약, 신약이면 채워주는 기운(인성·비겁)이 약. 재물·직업·결혼·건강·개운법 전 장이 이 저울 위에서 해석된다.

유료 평생사주 앱(포스텔러·점신·천명 류)의 표준 목차를 그대로 구현한다. **방대하게** 쓴다 — 각 장 최소 3~5문단, 두루뭉술한 미사여구 대신 **그 사람의 실제 간지·개수를 인용**해서 쓴다. (예: "월지 申金이 편관으로 작용하니…", "재성이 1개뿐이라 약하고 비겁이 2개로 강하니…" — 소수점 금지, 개수로)

성능을 위해 실제 생성은 반드시 이 순서를 따른다:
1. 엔진 JSON과 `references/interpretation.md`를 근거로 아래 18장을 먼저 끝까지 작성한다.
2. 18장 내용이 완성된 뒤, 그 내용을 근거로 `핵심 추정` 3종을 추가로 작성한다.
3. 최종 HTML 조립 때만 `핵심 추정` 3종을 18장보다 위에 배치한다.

즉, **생성 순서와 화면 배치 순서는 다르다.** 추정 섹션은 먼저 쓰지 않는다. 먼저 18장으로 명식의 뼈대를 충분히 세운 뒤, 그 결과를 재료로 삼아 대담하고 구체적인 추정을 만든다.

```
🔮 [이름/생년] 평생사주 풀이
   ─ 사용자 정보(년월일시·성별·출생지·보정 안내)
   ─ 명식 원국표 (연·월·일·시 8글자 + 일간 표시)
   ─ 오행 요약
   ─ 오행 밸런스
   ─ 십신 구조

핵심 추정 A  이 사람은 어떻게 살아왔을까
핵심 추정 B  이 사람의 직업은 무엇이었을까
핵심 추정 C  이 사람은 언제 결혼할 가능성이 높은가

제1장  총평 — 이 사주를 한 문장으로
제2장  타고난 성격과 기질 (일간론 + 일주론)
제3장  오행 밸런스 — 강약·과부족, 부족한 기운 보충법
제4장  십신 구조 — 비겁/식상/재성/관성/인성, 내 에너지 지도
제5장  격국과 그릇 — 사주의 스케일과 쓰임
제6장  용신 — 평생 나를 살리는 기운(색·방위·계절)
제7장  대운 흐름 — 10년 단위 인생 그래프 (유년기→노년)
제8장  재물운 — 돈의 그릇, 버는 방식, 절정기와 조심할 시기
제9장  직업·적성운 — 천직, 사업 vs 직장, 어울리는 분야
제10장 학업·시험·자격운
제11장 애정·결혼운 — 배우자 궁/성향, 만남·결혼 시기
제12장 건강운 — 약한 오행→장부, 평생 주의할 부분
제13장 대인관계·인복 — 귀인과 구설, 사회운
제14장 가족운 — 부모·형제·자녀 (육친)
제15장 신살 풀이 — 도화·역마·화개·천을귀인 등 + 12운성
제16장 평생 길흉 캘린더 — 황금기 vs 주의기 (대운 기반)
제17장 개운법 — 색·방위·직업·생활 처방
제18장 마무리 — 인생 총조언 한마디
```

### 작성 규칙 (유료 같은 퀄리티의 핵심)
- **분량**: 전체적으로 길고 진하게. 각 장이 짧으면 "유료 같지 않다". 단, 빈 말로 늘리지 말고 명식 근거로 채운다.
- **구체성**: 매 장마다 해당 근거를 최소 1개 명시 인용 — 단 **간지·개수·신강신약**으로(예: "월지 申金 편관", "재성 1개·관성 3개", "화가 없는 신강 사주"). **소수점 가중치는 금지**(위 강약 표현 규칙).
- **2인칭 상담체**: "~하십니다 / ~한 분입니다 / ~하는 시기입니다" — 차분하고 권위 있는 명리학자 존댓말 (기본).
- **시기는 대운 간지로**: "○○세(○○년~) ○○ 대운에 들어서면…" 식으로 daewoon 데이터를 인용.
- **단정 금지 항목**: 수명·사망·중병 확정·임신/낙태 단정·타인 사주 단정·법적/투자 확정 조언은 하지 않는다. 건강은 "약한 장부·관리 포인트" 수준까지만.
- **부적·굿·개명 강매 금지**: 개운법은 색/방위/생활습관/직업 방향 같은 무해한 처방까지만.
- **하단 면책**: 맨 끝에 한 줄 — "사주는 통계적 경향이자 참고이며, 인생은 본인의 선택으로 바뀝니다." 류.

### 핵심 추정 3종 작성 규칙

HTML 상단에는 "Appendix"라는 제목을 쓰지 않는다. 대신 `핵심 추정`, `대담한 명식 추론`, `명식으로 그려본 하이라이트`처럼 사용자가 먼저 보고 싶어지는 이름을 쓴다.

#### A. 이 사람은 어떻게 살아왔을까
이 스킬의 가장 차별화되는 섹션이다. 18장 전체에서 이미 정리한 일간·오행·십신·격국·용신·대운·신살을 근거로, 이 사주의 사람이 **시기별로 어떻게 살아왔을지 소름 돋게 구체적으로** 쓴다. 목표는 읽는 사람이 "어떻게 알았지?" 하고 소름 돋는 것 — 일대기 요약이 아니라 **그 사람의 어린 시절부터 지금까지를 옆에서 지켜본 것처럼** 쓴다.

**구간 나누기 & 헤더 형식**
- 유년기 → 초등~중학 → 고등학교 → 대학·군대·20대 초반 → 지금 → 앞으로 식으로, **대운 경계와 학제(입학·졸업·입대·취업)가 맞물리는 지점**에서 끊는다. 사주마다 대운 시작 나이가 다르니 구간 경계도 매번 달라진다.
- 각 구간 헤더는 `이모지 + 시기명 (나이 범위) — 그 시기를 한 줄로 붙잡는 별명` 형식으로 쓴다. 예: `🧒 유년기 (0~7세) — 조용하고 어른스러운 아이`, `🎧 고등학교 (16~18세) — 속으로 지치던 시기`, `💼 지금 (25~26세, 2026년 현재) — 진로의 갈림길`. 별명은 명식에서 도출된 그 시기의 정서를 담아야 하며, "성장기"류의 밋밋한 이름은 실패다.
- "지금" 구간은 반드시 현재 연도와 현재 나이를 명시하고, 지금 하고 있을 법한 **고민을 따옴표 화법으로 직접** 적는다("회사를 다녀야 하나, 내 일을 해야 하나").
- "앞으로" 구간은 다가올 대운 2~3개를 나이·연도와 함께 짚고, **용신이 살아나는 진짜 전성기 대운**을 굵게 못박는다. 마지막에 이 사람의 인생 그래프 유형(대기만성형/조숙형/파도형 등)을 규정한다.

**구간 내부 구조**
- 각 구간은 **첫 1~2문장에서 그 시기를 지배하는 명식·대운 근거를 요약**하고("戊土 일간에 년지 화개살, 8세부터 己丑 대운으로 土가 겹치는 시기였습니다"), 이어서 불릿 2~4개로 장면을 푼다. 근거 없이 장면부터 시작하지 않는다.
- 대운이 바뀌는 구간에서는 **무엇이 새로 들어오고 무엇이 풀리는지**를 명시한다("寅 속에 숨은 丙火가 들어오면서 없던 용신 火가 처음으로 공급되는 시기 — 이때부터 숨통이 트입니다").

**장면 서술 문체 (예시 톤을 그대로 재현할 것)**
- **주변 사람들 입에서 나왔을 법한 말을 따옴표로 직접 인용**한다: "혼자서도 잘 노는 애", "쟤는 무슨 생각을 하는지 모르겠다", "말은 참 잘하는데 좀 건방지다". 이 인용 화법이 이 섹션의 핵심 장치다 — 구간마다 최소 1개.
- 장면은 **시대와 나이에 맞는 구체적 디테일**로 그린다: 어린이집 블록놀이, 조별과제 조장, 야자 시간, 군대, 사이드 프로젝트. "학창 시절에 어려움이 있었을 겁니다"처럼 뭉뚱그리면 실패.
- 명리 용어는 한자 병기 후 **곧바로 일상어로 번역**한다: "관성은 규율·통제·'시키는 대로 하는 힘'인데 이게 없어요", "상관은 '할 말은 하는' 기운입니다". 용어를 던져놓고 해석 없이 넘어가지 않는다.
- **양면성과 아이러니를 포착**한다: 부모에겐 편한 아이였지만 정작 속마음은 표현 못 했다든지, 인기는 많은데 연애는 서툴다든지. 한 구간에 좋은 면만 나열하면 가짜 같다.
- 톤은 18장 본문(정중한 상담체)보다 **한 톤 가볍고 구어적으로**. "이게 없어요", "~였을 법합니다", "~하는 장면이 그려집니다", "어, 나 이거 잘하네" 같은 해요체·혼잣말 섞기를 허용한다. 주어는 3인칭 "이 사람".
- 추정 화법을 유지한다: "~했을 겁니다 / 가능성이 큽니다 / ~였을 수 있습니다". 과거는 진하게 쓰되 사실처럼 박지 않고, 미래는 예측으로 명확히 구분한다.

**근거와 소재 선택**
- 모든 장면은 근거를 붙인다. `월주 정관+정인`, `무관성`, `식상 4개 과다`, `18세 庚寅 대운`, `火 없음`처럼 엔진 데이터에서 나온 말만 근거로 쓴다.
- 소재 후보(가정/부모 분위기, 학습·성적 패턴, 조직 적응, 돈 다루는 방식, 관계·연애 패턴, 몸과 마음의 소진, 이동·독립, 창작·표현·억압 등)는 **탐색 렌즈**일 뿐이다. 명식에 강하게 뜨는 범주만 고르고, 미리 정해진 슬롯을 채우듯 쓰지 않는다 — 사주마다 다른 조합이 나와야 한다.
- 수명·사망·중병·임신/낙태·불법·투자 확정은 쓰지 않는다.

**마무리 (필수)**
- 구간 서술이 끝나면 `한 문장으로 이 사람의 삶` 소제목을 달고, 인용구 스타일로 **인생 전체를 압축한 한 문장**을 쓴다. 예: "겉은 듬직한 산인데 속엔 표현 못 한 재능과 열망이 가득한 사람. 어릴 땐 눌려 있었고, 20대에 재능을 발견했고, 중년 이후에 진짜 꽃피우는 대기만성의 삶."
- 이어서 짧은 문단으로 **이 사람이 반복적으로 겪었을 테마 2~3개**를 짚고, 그것을 뚫는 열쇠가 무엇인지(대개 용신)를 굵게 연결하며 끝낸다.

#### B. 이 사람의 직업은 무엇이었을까
제9장 직업·적성운을 바탕으로, 실제 직업 후보를 대담하게 좁힌다.

- 1순위 후보 1~3개를 랭킹으로 제시한다.
- 각 후보마다 `왜 이 직업인가`를 명식 근거 3개 이상으로 설명한다.
- "안 맞았을 직업"도 2~4개 제시해 대비를 만든다.
- 직업명은 넓은 산업명만 쓰지 말고, 가능한 한 실제 역할명으로 쓴다. 예: "공공기관 행정·감사", "품질관리/검수", "교사·연구직", "회계·세무·법무 문서직".

#### C. 이 사람은 언제 결혼할 가능성이 높은가
새로 추가된 핵심 추정이다. 제11장 애정·결혼운을 바탕으로, 명식상 가장 유력한 결혼 시기를 구체적으로 예측한다.

- 성별에 따른 배우자 별(남성=재성, 여성=관성), 일지 배우자궁, 대운, 세운, 합·충·형·해 가능성을 함께 본다.
- "가장 유력한 결혼 시기"를 1순위로 제시한다. 가능하면 `나이 + 연도 범위 + 대표 연도`까지 좁힌다.
- 이미 결혼했을 법한 나이라면 "실제 결혼이 있었다면 이 구간이 가장 강하다"로 쓴다. 미혼/미래 질문이면 앞으로의 유력 구간을 별도로 쓴다.
- 근거 없는 확정은 금지한다. "반드시 결혼"이 아니라 "명식상 결혼 이벤트가 가장 강하게 뜨는 구간"으로 표현한다.
- 결혼운이 약한 명식이라도 회피하지 말고, `늦어지는 이유`, `성사 조건`, `피해야 할 시기`, `현실적으로 가장 잘 맞는 배우자상`까지 적는다.

## 4. HTML 리포트 조립 및 열기

최종 결과는 채팅에 장문 텍스트로 출력하지 않는다. 반드시 HTML 파일로 만든다.

1. `references/saju-report-template.html`을 템플릿 껍데기로 읽는다.
2. 템플릿 안의 플레이스홀더와 샘플 구조를 실제 명식 데이터와 생성된 해석으로 채운다.
3. 최종 화면 순서는 다음처럼 둔다:
   - 사용자 정보: 생년월일시, 성별, 양력/음력, 출생지, 진태양시 보정, 경고
   - 명식 원국표: 연·월·일·시 8글자와 일간 표시
   - 오행 요약
   - 오행 밸런스: `counts.ohaeng` 개수와 등급
   - 십신 구조: `counts.shipsinGroup` 개수와 등급
   - 핵심 추정 A/B/C
   - 18장 본문
   - Q&A 안내와 면책
4. 파일명은 가능하면 `saju-YYYY-MM-DD.html` 또는 `saju-<사용자식별자>.html`처럼 만든다.
5. 저장 후 반드시 `open "<HTML_FILE>"`을 실행해 사용자가 바로 볼 수 있게 연다.
6. 최종 응답은 장문 풀이를 반복하지 말고, 열린 파일 경로와 "이제 질문을 이어가도 된다"는 정도만 짧게 말한다.

### 템플릿 사용 규칙
- `references/saju-report-template.html`은 기존 1970년 예시 내용을 제거한 껍데기다. 거기에 남아 있는 플레이스홀더 문구를 그대로 사용자에게 보여주면 실패다.
- 원본 템플릿의 Toss 스타일, 카드 구조, 진행바, 목차, 타임라인, 랭킹 카드 감각은 최대한 유지한다.
- 오행/천간/지지는 한자만 크게 보이고 한글이 작아지면 안 된다. `辛 신`, `巳 사`, `火 화`처럼 **한자와 한글을 나란히** 두고 같은 폰트 크기·굵기·색으로 맞춘다.
- 오행 막대도 `木 목`, `火 화`, `土 토`, `金 금`, `水 수`를 나란히 표기한다. 한글을 보조 캡션처럼 작게 만들지 않는다.
- 원본 예시의 1970년생 해석, 문단, 직업 추정, 인생 시나리오는 절대 재사용하지 않는다.

## 5. 풀이 종료 → Q&A 상담 모드

이후 사용자의 모든 질문은 **이미 계산된 그 명식 데이터에 근거해서** 답한다. 새 명식이 필요한 질문(다른 사람, 궁합)이면 그 사람 생년월일을 받아 엔진을 다시 호출한다. 매번:
- 질문에 해당하는 기둥/십신/대운/세운을 짚어 근거를 댄 뒤 해석.
- 올해/특정연도 운세는 그 해 간지를 일간과 대조해 세운으로 풀이(필요시 엔진 재호출로 해당 연도 명식 확인).
- 단정 금지·부적굿 금지 원칙은 Q&A에서도 동일 유지.

세션이 이어지는 한 같은 명식을 기억하고 상담을 계속한다.
